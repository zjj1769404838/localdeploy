# 03 配置与接口契约 — LocalDeploy v1

> 本文是 config.yaml schema、IPC 通道、状态机枚举的唯一权威来源；代码类型定义必须与本文锁步（改语义同步文档与测试断言）。

## 1. config.yaml
位置：`%APPDATA%\LocalDeploy\config.yaml`。首次运行生成默认值。UTF-8，LF。

```yaml
version: 1                      # schema 版本，当前固定 1
settings:
  gateway:
    httpPort: 80                # int 1..65535；冲突仅提示不回退
    httpsPort: 443              # int；httpsEnabled=false 时不监听
    httpsEnabled: false         # 全局总开关（Q20b）
    httpsRedirect: true         # httpsEnabled 时 80 → 443 301（Q22）
  domain:
    suffix: ".zjj"              # 域名后缀（Q18a 用户自定义）
    hostsManaged: true          # 是否托管 hosts 区块写入
  proc:
    restartOnCrash: true        # 全局默认（项目可覆盖）
    backoffBaseMs: 1000         # 退避基数（Q10）
    backoffCapMs: 30000         # 退避封顶
    maxRestarts: 5              # 连败上限 → crashed
    killTimeoutMs: 10000        # 树杀后复检窗口
  logs:
    ringLines: 2000             # 内存环形行数
    fileSizeMb: 5               # 滚动单文件大小
    fileKeep: 3                 # 滚动保留份数
  autostart:
    appOnBoot: false            # HKCU Run 开机自启（Q11）
    resumeProjects: false       # 启动时按 desired 自动拉起
projects:
  - id: p-a1b2c3                # 创建时生成不可变（p-+6位base36）
    name: 示例前端               # 显示名
    domain: shili-qianduan.zjj  # slug(name)+suffix；可手改；空串=不域名
    type: static                # static | process
    # --- type=static ---
    dir: D:\sites\demo\dist     # 静态根目录
    spa: true                   # SPA 回退 index.html（Q13）
    # --- type=process ---
    command: npm                # 可执行程序
    args: ["run", "start"]      # 参数数组
    cwd: D:\projects\api        # 工作目录
    env: {}                     # 追加环境变量（key:value）
    port: 3001                  # 上游端口（网关转发目标 + 直链展示）
    # --- 通用 ---
    autoStart: false            # 本项目是否随应用恢复拉起
    restartOnCrash: null        # null=跟随全局 settings.proc.restartOnCrash
```

### 1.1 校验规则（fail-closed，非法项拒绝整次保存并回传错误）
- `name` 非空 ≤64 字符；`domain` 若启用须匹配 `^[a-z0-9]([a-z0-9-]*[a-z0-9])?(\.[a-z0-9]([a-z0-9-]*[a-z0-9])?)+$` 且以 suffix 结尾。
- `type=static` 必有 `dir`（存在性软校验：不存在仅警告）；`type=process` 必有 `command` 与 `port∈1..65535`。
- `id` 唯一；`domain` 在项目间唯一（非空时）。
- settings 数值范围见注释；越界拒绝。

### 1.2 托管块（hosts 文件）
```
# BEGIN LOCALDEPLOY MANAGED (do not edit between markers)
127.0.0.1  shili-qianduan.zjj
::1        shili-qianduan.zjj
# END LOCALDEPLOY MANAGED
```
区块外内容逐字节保留；重复 begin 标记视损坏 → 拒绝写并警告。

## 2. IPC 通道契约（preload 白名单）
invoke 通道（渲染→主，均返回 `{ok:true,data}|{ok:false,code,message,warnings[]}`）：

| 通道 | 入参 | 出参 data |
|------|------|-----------|
| `state:get` | – | `{projects:ProjState[], settings, warnings[]}` 全量快照 |
| `project:add` | `ProjectSpec` | `Project`（含生成 id/domain）；识别预检走 `project:detect` |
| `project:detect` | `{dir}` | `{type,command?,args?,dir?,spa?,port?}` 向导预填 |
| `project:update` | `{id, patch}` | `Project` |
| `project:remove` | `{id}` | `null`（先停后删再清 hosts） |
| `project:start` / `project:stop` / `project:restart` | `{id}` | `ProjStatus`；start 置 desired=true |
| `logs:get` | `{id, sinceSeq?, limit?}` | `{lines:[{seq,t,line,stream}], eof}` |
| `logs:clear` | `{id}` | `null` |
| `settings:update` | `Partial<Settings>` | `Settings`（触发热应用 diff） |
| `hosts:retry` | – | `{warnings[]}` 重放区块写入（再弹 UAC） |
| `certs:status` / `certs:renew` | – | `{installed,notAfterIso?}` / 同 |
| `app:quit` / `window:show` | – | `null` |

event 通道（主→渲染）：`state:patch`（项目状态/警告变更，节流 100ms）、`log:line`（批量行）、`settings:changed`（外部编辑热加载回声）、`config:error`（热加载解析失败）。

## 3. 状态机枚举
`ProjStatus = idle | starting | running | stopping | stopped | crashed`（语义见 docs/02 §3.2；UI 色：running 绿 / starting·stopping 黄 / stopped·idle 灰 / crashed 红）。

警告码：`W_HOSTS_DENIED`（提权失败/取消）、`W_HOSTS_CORRUPT`（标记损坏拒写）、`W_CERT_UNAVAILABLE`（mkcert 失败降级 HTTP）、`W_GATEWAY_BIND`（端口冲突）、`W_DIR_MISSING`（静态目录不存在）、`W_AUTOSTART_DENIED`（注册表写失败）。

## 4. 版本与锁步
应用 semver 从 `0.1.0` 起；version 定义唯一点 `package.json`，README/docs 不重复硬编码（构建注入）。schema `version` 字段升位时提供迁移函数并保留旧文件备份 `config.yaml.bak-<ts>`。
