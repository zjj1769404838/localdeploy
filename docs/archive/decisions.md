## 贯穿原则

能自动的不手填、能默认的不追问、能配置的不写死、权限失败不阻塞。

## 硬约束

- 全免费开源依赖（Electron MIT / Vue MIT / Naive UI MIT / mkcert BSD / electron-builder MIT）
- 日常运行无管理员；仅 hosts 写入、根 CA 安装两个动作按需 UAC
- 凭据零落盘；私钥/CA 材料仅存 %APPDATA%，不进 git 不进日志
- 代码签名（~$500/年）排除——零成本原则；SmartScreen 提示以 README 说明应对
