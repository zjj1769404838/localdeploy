# 02 技术方案 — LocalDeploy v1

## 1. 选型结论（依据见 docs/04）
**Electron + Node.js 引擎 + Vue 3/Vite/TypeScript/Naive UI**。
理由：本机 node v22.19.0 / npm 10.9.3 / git 2.47.1 现成，go/rustc/gcc 均未安装，WebView2 Runtime 缺失（Edge 在）——Electron 是唯一零新增工具链即可开工的路线；自带 Chromium 无 WebView2 依赖。体积代价（~100MB）换取环境确定性，符合自用场景。调研来源：[クロスマート三框架同项目实测](https://xmart-techblog.hatenablog.com/entry/2025/09/01/110000)、[CSDN Windows 轻量客户端对比](https://www.csdn.net/detail/webblog_38637020/35450)。

## 2. 进程与模块架构
```
┌─ Electron Main Process ──────────────────────────────┐
│ bootstrap（单实例锁/窗口/托盘/菜单）                    │
│ ipc（contextBridge 白名单路由）                         │
│ engine/  ← 纯 Node，可脱离 Electron 单测与演练           │
│   config.ts    加载/校验/保存/chokidar 热加载/diff 应用  │
│   procman.ts   子进程状态机/spawn/树杀/退避重启          │
│   staticsrv.ts 静态伺服 + SPA 回退（http.Server 内置）   │
│   gateway.ts   按 Host 反代分流 + 301 + 端口冲突        │
│   hosts.ts     托管区块读写 / 提权自举 / 降级警告        │
│   certs.ts     mkcert 子进程：-install / *.zjj 签发     │
│   autostart.ts HKCU Run 读写（reg.exe）                 │
│   logs.ts      环形 2000 行 + 5MB×3 滚动落盘            │
│   detect.ts    项目类型自动识别                          │
└──────────────────────────────────────────────────────┘
┌─ Renderer (Vue3 SPA, vite 构建后打包进 asar) ─────────┐
│ Dashboard 卡片 / AddWizard 向导 / LogDrawer / Settings │
│ / Onboarding 三步引导                                  │
└──────────────────────────────────────────────────────┘
```
原则：**engine 零 electron 依赖**（仅 node API + js-yaml + chokidar），Electron 只是宿主；drill/e2e.mjs 直接以纯 Node 起 engine 演练。

## 3. 关键设计
### 3.1 配置双通道热加载（FR-11）
- 单一事实源 `config.yaml`（schema 见 docs/03）。保存路径：UI 变更 → engine.config.update() → 原子写（tmp+rename）→ chokidar 观察到自身写（以内容 hash 去重，防自激）。
- 热加载 diff：settings 端口/HTTPS 变更 → 网关重启；projects 增删改 → 同步 procman 与路由表。解析失败 → 保留旧配置 + 错误 toast，不崩。

### 3.2 进程状态机（FR-3/4/15）
`idle → starting → running → stopping → stopped`；异常退出 `running → (退避等待) → starting …` 或 5 连败 → `crashed`。desired 持久（autoStart 或用户手动起后置 true），应用启动按 desired 恢复。退避 `min(base * 2^(n-1), cap)`。Windows 树杀：`taskkill /pid /T /F`，兜底 kill。

### 3.3 网关（FR-5/6/8）
- Node `http.createServer` + `net` 自管：按 `req.headers.host` 去端口查路由表 → 管道转发（http-proxy 库或手写透传，v1 用 node-http 原语手写，零依赖）。HTTPS 用 `https.createServer(cert)`，证书缺失/加载失败 → 只起 HTTP + 警告。
- 端口冲突：`server.listen` EADDRINUSE → 状态 error + UI 红字提示去设置页改端口（**不自动回退**，Q19 拍板）。
- HTTP→HTTPS 301 仅在 HTTPS 开启时；管理页不在网关内（渲染进程即 UI）。

### 3.4 hosts 托管（FR-6/7）
- 专用区块 `# BEGIN LOCALDEPLOY` / `# END LOCALDEPLOY`，只改本区块。
- 普通权限尝试直接写；EACCES/EPERM → 走提权：临时生成 `.bat` 并以 `powershell Start-Process -Verb RunAs`（触发一次 UAC）执行提权 helper（本 exe `--elevated-hosts <tmpjson>` 子命令），回读核验区块生效后删除临时文件。
- 用户在 UAC 取消/失败 → 记警告 `W_HOSTS_DENIED`，项目照常运行，UI 琥珀徽标「域名未生效」。
- 测试桩：hosts 路径注入（Options.hostsPath），单测/演练全部用临时目录，禁碰真机 hosts。

### 3.5 mkcert 捆绑（FR-8）
- `resources/mkcert/mkcert.exe`（v1.4.4 windows-amd64，BSD-3；下载源 GitHub Release，构建时校验 SHA-256 固定）。
- 环境变量 `CERTIFICATE_STORE`/`CAROOT` 指向 `%APPDATA%\LocalDeploy\caroot`（隔离于用户已有 mkcert）。
- 首启 HTTPS：`mkcert -install`（内部自弹 UAC）→ `mkcert -cert-file -key-file *.zjj zjj`；证书过期（825 天）前 30 天 UI 提醒重签。
- mkcert 缺失/失败 → 降级 HTTP + 警告。

### 3.6 域名（FR-1/6）
`slug(项目名) + settings.domainSuffix(.zjj)`；slug 小写、去非法字符、连字符；冲突自动加 `-2`。后缀可配置（Q18a 自定义为 .zjj）。

### 3.7 Electron 装配（FR-13）
单实例锁；ready-to-show 显窗；close → hide 到托盘；托盘菜单 + 双击回窗；退出时 engine.shutdownAll()（先停 desired 的进程树再退）。IPC 白名单 invoke 通道 + `log:<projectId>` 事件推送（批量 100ms 合并）。

## 6. 测试策略
- 单测（Vitest, node env）：config 解析/校验/热加载、logs 环形+滚动、procman 状态机与退避计算（假时钟）、detect 各形态、hosts 区块算法（临时文件）、gateway 路由匹配与 301（随机端口真 http）。
- 演练（drill/e2e.mjs）：随机非特权端口 + 临时目录 + hostsPath 桩，跑 FR-2/3/4/9/15 + 降级路径，断言 stdout JSON 报告。
- 审核：subagent 独立只读审核 → docs/review/ 报告 → 销项。

## 7. 打包与交付
electron-builder：`portable`（主）+ `nsis`（辅）；`npmRebuild:false`；产物 `build/LocalDeploy-<ver>-portable.exe` / `setup.exe`；README 记录 SHA-256；GitHub Release 作为下载链接源；SmartScreen：README 说明「仍要运行」步骤（不签名拍板）。

## 8. 已知风险与对策
| 风险 | 对策 |
|------|------|
| npm 拉 electron 二进制慢/失败 | npmmirror 镜像 env（ELECTRON_MIRROR）；失败重试 |
| 80/443 被占（http.sys/IIS） | 冲突仅提示 + 设置页改端口引导（Q19 拍板） |
| 提权 UAC 被拒 | 全链路降级警告（FR-7），端口直连兜底 |
| mkcert -install 失败 | 降级 HTTP；日志与 UI 展示 mkcert stderr |
| WebView 渲染差异 | Electron 捆绑 Chromium，天然一致（选型红利） |
| 进程树杀不净（node 再 spawn） | taskkill /T /F 树杀 + 10s 后存活复检 |
